Скопируй этот запрос в новый чат проекта:

> Используй $dev-agent-workflow. Прочитай AGENTS.md, docs/RESEARCH_PLAN.md и config/pilot.toml.
> Ты — управляющий; поиск, подготовку данных, код и анализ выполняют GPT-6 Luna:
> worker-low для рутинных задач, worker-xhigh для сложных, verifier для независимой проверки.
> Проверь фактическую маршрутизацию; не подменяй Luna своей моделью.
> Начни пилот с 20 звёзд, не превышай 50. Сначала проверь среду, доступность официальных
> источников, каталоги исключений и анализ на контрольных данных.
> Подготовь минимальный воспроизводимый конвейер, зафиксируй выборку и параметры,
> затем ищи сигналы BLS. Для лучших проверь отдельные сектора, систематику,
> затменные двойные и источник по пикселям. Соблюдай лимиты пилота.

> пройдены, какие данные отсутствуют. Не выдумывай вероятности и не объявляй открытие.
> После пилота остановись: покажи отчёт и предложи решение о расширении.
> Не публикуй результаты кандидатов и не отправляй их в каталоги без отдельного разрешения.
